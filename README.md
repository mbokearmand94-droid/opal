# Opal

Opal — squelette d'une application de montage vidéo mobile (prototype inspiré de CapCut).

Stack choisi
- Client: React Native + Expo
- Backend: Node.js + Express

Licence: MIT

Démarrage local

1. Installer les dépendances du client:

   npm install

2. Lancer l'app Expo:

   npm run start

3. Lancer le backend:

   cd backend
   npm install
   npm run start

Ce dépôt contient un scaffold minimal. Je vais maintenant créer une branche `feat/init-expo` avec le squelette si tu confirmes que je pousse cette branche. Si tu veux que je pousse tout de suite, dis "pousse".
